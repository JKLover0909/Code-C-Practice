# Code_C++
Code C++ Tin học cơ sở

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---|---|
| `ptit/` | Bài nộp PTIT đặt tên theo mã đề `CPPxxxx.cpp` (kèm `DATA.txt` cho `CPP0801.cpp`) |
| `bai-tap/` | Bài luyện đặt tên theo đề (số học, mảng/ma trận, xâu, hình ký tự, quay lui, lớp đối tượng...) |
| `nhap/` | File nháp (`Untitled*`, `test.cpp`, `xx*.cpp`, `hihi.cpp`) |

Mỗi file là một chương trình độc lập:

```bash
g++ -std=c++17 -O2 bai-tap/songuyento.cpp -o songuyento
```
